---
## Note: You will need to download [BUG Clicker](https://github.com/BUG-INVADE/Bug-Clicker-download) to import the `.cvclk` file.
Contents:
* `MNTR-main clickers.cvclk`: Individual characters of 🐍 and 🐯, with customizable lines.
* `objects`: Includes the `.cvpart` files for cat objects and the sweating effect when character is dragged.
